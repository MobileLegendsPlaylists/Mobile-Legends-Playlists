# Mobile Legends Playlists Website

## Files
- `index.html` — Home
- `gallery.html` — Image gallery
- `links.html` — YouTube/TikTok/Instagram/Facebook
- `about.html` — About page
- `style.css` — Black/red/silver design and responsive layout
- `script.js` — animations and small interactions
- `images/` — your uploaded logos

## Add your social links
Open `links.html` and replace each `href="#"` with your real URL.

## Add pictures
Put your images into `images/`, then add gallery cards in `gallery.html`.

## Free hosting
This site is static, so it can be hosted for free with GitHub Pages, Cloudflare Pages, or similar static hosting.
